## RACI

A — отвечает за результат; R — выполняет; C — консультирует; I — информируется. В небольшом учебном проекте A/R допустимо совмещать.

| Работа | Олег | Михаил | Гоша | Даниил | Андрей |
|---|---|---|---|---|---|
| Требования и приёмка | C | A/R | C | C | C |
| Документы и разметка | I | A | C | R | C |
| Поиск и качество RAG | C | C | A/R | R | C |
| БД, права и загрузка | C | C | C | R | A/R |
| Интерфейс | A/R | C | C | I | C |
| Запуск и CI | A | I | C | C | R |
| Демо и защита | A/R | R | R | R | R |

## План из трёх итераций

Это план работ, а не новые согласованные с преподавателем календарные сроки.

1. Требования, роли, синтетический корпус, классический retrieval, эталонные вопросы.
2. LLM-ответы, источники, публикация документов, роли, обработка конфликтов и недостатка сведений.
3. Метрики, сравнение TF-IDF/FastText, проверки доступа, запуск, репетиция и отчёт.

Перед защитой Михаил проверяет соответствие сценария договорённостям, Даниил — источники и разметку, Гоша — воспроизводимость измерений, Андрей — запуск и доступы, Олег — цельный пользовательский сценарий.
