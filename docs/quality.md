# Качество и границы проверки
Исходная учебная база содержит восемь записей и семь действующих разделов. Далее — измерения локального режима, без сетевой задержки Elasticsearch. Повторить: `python -m kb.evaluate`. Все результаты по вопросам — в [evaluation-local.json](evaluation-local.json).

* Отложено 9 из 15 размеченных вопросов. Из них 6 имеют эталонный раздел, 2 требуют отказа, 1 — передачи противоречия тимлиду. Во всех 9 случаях совпали ожидаемое поведение и, для ответа, источник.
* На 6 вопросах с эталонным источником: macro precision@3 = 0,333, recall@3 = 1,000. Для каждого вопроса размечен только один подходящий раздел. В знаменателе precision всегда 3, даже если найден один раздел; это ограничивает максимум точности на этом наборе значением 1/3.
* Это небольшой синтетический набор и проверка на том же корпусе. Метрики не доказывают качество на данных банка и не оценивают произвольные формулировки. Известное ограничение: лексический поиск может не распознать незнакомые синонимы; разные по написанию равноприоритетные указания консервативно считаются спорными.
* Локальный тест интерфейса с одним запросом: 37,7 МиБ пикового RSS процесса Streamlit AppTest, SQLite при старте занимает 24 КиБ. Тестовая Linux-среда: процессор AMD EPYC 9V74, лимит 8 CPU. Медиана локального поиска на 9 запросах — в JSON-отчёте. Это не минимальные требования всей системы.

## Проверка Docker Compose на чистом стенде

3 ноября 2026 г. на Ubuntu 24.04 в GitHub Actions запущены Streamlit 1.50.0 и Elasticsearch 8.17.4. Внешний HTTP-запрос к Streamlit на `127.0.0.1:8501` вернул `ok`. Elasticsearch доступен приложению по внутренней сети; его порт не опубликован на хосте.

С реальным Elasticsearch все 7 автоматических тестов прошли без пропусков. На отдельном наборе из 9 вопросов совпали все 9 ожидаемых исходов. Для 6 вопросов с источником: precision@3 = 0,333, recall@3 = 1,000. Медиана времени запроса на этом прогоне — 8,13 мс. Это показатель на маленьком синтетическом корпусе, без времени отрисовки браузера.

В Chrome прошёл весь сценарий из [demo.md](demo.md): открытие действующего раздела v2; запрет закрытого источника и повторного вопроса после смены роли; передача конфликта тимлиду; отказ при отсутствии данных; загрузка файла и публикация v3 только после одобрения. В новой сессии браузера опубликованная инструкция также доступна.
