# Показ за несколько минут
Начните с исходной базы. Файл для демонстрации обновления: `data/update-example.json`.

1. **Обычный вопрос.** Профиль «Стажёр ИБ», запрос «Как стажёру запросить доступ к реестру инцидентов?». Показать шаги и открыть раздел `access@2#request`. Не должна появиться прежняя бумажная инструкция.
2. **Разные права.** Спросить «Как классифицировать инцидент по влиянию?». Открыть источник. Не меняя ссылку, переключиться на «Стажёр поддержки»: раздел становится недоступным, повтор вопроса не раскрывает закрытый текст.
3. **Противоречие.** Для ИБ спросить «Какой срок эскалации критического инцидента?». Две инструкции равноприоритетны, поэтому ассистент предлагает обратиться к тимлиду, не выбирая 15 или 30 минут.
4. **Нет ответа.** Спросить о командировке. Ассистент сообщает об отсутствии ответа в доступных материалах.
5. **Обновление.** Предложить файл новой инструкции от имени стажёра. До публикации ответ не меняется. Выбрать демопрофиль тимлида, проверить содержимое и утвердить. Вернуться к первому вопросу: теперь в ответе версия 3 с кодом КУРС-03. Повторно утверждать ту же версию нельзя. Для следующих показов используйте отдельный `KB_DB` или том.
