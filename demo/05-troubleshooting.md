# Если что-то не получилось

Начните с текста ошибки и команды/действия, после которого она появилась. Не нужно сразу удалять базу, заново клонировать проект или менять все настройки.

| Симптом | Что проверить и сделать |
|---|---|
| `target not found: ollama` в pacman | Убедиться, что используются актуальные зеркала и включён официальный Extra; обычная установка — `sudo pacman -Syu ollama`. Не делать отдельный частичный `pacman -Sy` перед установкой |
| Ollama не запущена | `systemctl is-active ollama`, затем `sudo systemctl start ollama`; диагностика `journalctl -u ollama -n 50 --no-pager` |
| `address already in use` на 11434 | Скорее всего Ollama уже работает как служба. Не запускать второй `ollama serve`; проверить `ollama list` |
| Модели нет | `ollama pull qwen2.5:1.5b`, затем `ollama list`. Имя модели должно совпадать с настройкой приложения |
| «Не удалось получить ответ модели» | Выполнить явный локальный `scripts/check_model.py` из руководства запуска; проверить службу и адрес. Если используете launcher, посмотреть напечатанные модель/URL |
| Ответ не опубликован из-за JSON, цитаты или чисел | Запрос дошёл до модели, но результат не прошёл проверку. Сохранить вопрос и ошибку, попробовать более точную формулировку. Для проверки retrieval можно явно выбрать «Поиск по инструкциям», не называя его генерацией |
| Ответ модели медленный | Первый запрос может загружать веса. Прогреть заранее, закрыть лишние тяжёлые процессы, использовать короткий вопрос по одной операции. В составном вопросе несколько вызовов идут последовательно |
| Порт 8501 занят | Остановить своё прежнее приложение Ctrl+C либо запустить `demo/start_demo.py --port 8502` и открыть 8502 |
| Получился старый интерфейс | `git branch --show-current` должен показать `feature/ai-assistant`; проверить папку, из которой выполняется команда, получить обновления без удаления своей работы |
| Ошибки зависимостей Python | Использовать Python 3.12 и `.venv/bin/python`, установить `requirements.txt` в это окружение. Системный Python Arch может быть другой версии |
| Не виден переключатель ролей | Обычный запуск требует входа. Для учебных профилей используйте `demo/start_demo.py` или явный `run_local.py --demo` |
| Без `--demo` всё равно видны профили | В окружении или `.env` осталось `KB_DEMO_MODE=true`. Для настоящего входа явно задайте `env KB_DEMO_MODE=false .venv/bin/python run_local.py` |
| Пользователь создан, но вход не работает | CLI и сайт могли открыть разные `KB_DB`. Пользователей нужно создавать в том же файле базы, что используется приложением. У репетиции и рабочей базы разные пути |
| Исходные инструкции уже есть | Это нормально: новая база автоматически наполняется из `data/documents.json`. Для основного показа не загружайте справочные копии повторно |
| JSON: «Ожидается один JSON-объект» | Не загружайте `data/documents.json` или manifest целиком. Выберите один подготовленный JSON из `02-upload` либо `03-updates` |
| Обычный файл не отправляется | Заполнить название, id, систему, ответственного, версию, приоритет, роли и **вручную тему/операцию**. Точное соответствие — в `files/README.md` |
| PDF без текста | Нужен PDF с текстовым слоем, не скан. Для примера используйте готовый PDF из набора; OCR в проекте не реализован |
| Кириллица испорчена в TXT | Пересохранить файл в UTF-8, не Windows-1251 |
| «Версия должна быть новее» | Тот же id/версия уже опубликованы. Для реального обновления увеличить версию; для повторения исходного сценария создать новую репетицию |
| После отправки файла нового ответа нет | Отправка создаёт pending. Тимлид должен проверить и утвердить. После публикации выбрать систему документа и задать вопрос заново |
| После утверждения очищена история | Это ожидаемо: изменился опубликованный снимок. Нужен новый запрос, чтобы не показывать устаревший ответ |
| Есть инструкция, но поиск не находит | Проверить выбранную систему, права, утверждение и точность вопроса. У обычного файла проверить тему/метаданные; у JSON — поля внутри файла. Неизвестные формулировки и несовершенный поиск тоже возможны |
| Закрытый документ не виден поддержке | Это ожидаемый результат. Для проверки сравнить того же запроса в профиле ИБ и поддержки; не повышать права документа ради ответа |
| Нет подписи модели при отказе/конфликте | Такой результат может быть определён до генерации. Проверять связь с моделью положительным вопросом, а не только отказом |
| В panel тимлида нет конфликтного вопроса | Автоматическая отправка вопроса в очередь не реализована. «Согласование» содержит предложения документов; сообщение о конфликте рекомендует обратиться к тимлиду |
| Elasticsearch недоступен | Проверить адрес и запущенный сервис. Для хостового приложения использовать optional override и `--backend elastic`; обычный `run_local.py` всегда выбирает local |
| Изменили seed JSON, а сайт старый | SQLite уже заполнена. Для рабочей базы — новая версия через публикацию; для репетиции — новый запуск `demo/start_demo.py` |
| После запуска Docker «пропали» файлы/модель | Docker использует другие тома SQLite/Ollama, не хостовую `.local` и не хостовую модель. Не смешивайте топологии; вернитесь к выбранному маршруту запуска |

## Начать показ заново

Остановите приложение Ctrl+C и выполните:

```bash
.venv/bin/python demo/start_demo.py
```

Будет новая база с исходной v2, без опубликованных новых демонстрационных инструкций. Предыдущие базы сохраняются. Для ES-показа повторите `--backend elastic`.

## Продолжить текущую репетицию

```bash
.venv/bin/python demo/start_demo.py --resume .local/demo/ИМЯ_ВАШЕГО_ПОКАЗА/handbook.sqlite
```

Подставьте путь, напечатанный предыдущим запуском. `--resume` сохраняет базу, **но параметры backend/модель/URL/порт берутся из текущих флагов**, не восстанавливаются автоматически из `run.json`. Для ES и нестандартных параметров повторите их явно:

```bash
.venv/bin/python demo/start_demo.py \
  --resume .local/demo/ИМЯ_ВАШЕГО_ПОКАЗА/handbook.sqlite \
  --backend elastic --es-url http://127.0.0.1:9200 --port 8502
```

## Что прислать для разбора ошибки

- Точную команду запуска, ветку и версию Python.
- Режим ответа, профиль и выбранную систему.
- Точный вопрос; при загрузке — имя файла и указанные метаданные.
- Текст ошибки или соответствующий небольшой фрагмент лога.

Не присылайте пароли, токены GigaChat, полный `.env` с секретами или реальные внутренние документы. Для воспроизведения достаточно учебного примера из этого набора.
