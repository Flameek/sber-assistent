# Что проверено для этого набора

Проверка материалов — **8 ноября 2026 года**. Это проверка подготовленного учебного сценария, не оценка произвольных документов или банковских данных.

| Проверка | Результат |
|---|---|
| TXT, MD, DOCX, PDF, JSON через настоящий импортёр | Все пять файлов импортируются |
| До предложения и при pending | Подтверждённого ответа по каждому новому вопросу нет |
| После утверждения | Каждый вопрос находит ожидаемый источник и контрольный маркер |
| Все пять файлов в одной базе | Не мешают друг другу; источники и маркеры соответствуют вопросам |
| Права DOCX | ИБ видит инструкцию, поддержка не получает текст и не открывает источник |
| v2 → утверждение v3 → отклонение v4 | Активна v3 с КУРС-03, КУРС-04 не используется |
| Launcher | Создаёт разные базы, возобновляет свою репетицию, не принимает произвольную рабочую базу для --resume |
| Настройки launcher | Явно задают локальную модель, запрет внешнего API и выбранный backend, даже при противоречащем окружении |
| Основной TXT с настоящей моделью | Qwen2.5-1.5B-Instruct Q4_K_M через локальный llama.cpp сформировала ответ с источником и ТЕЛЕМЕТРИЯ-21 |
| Тот же TXT в браузере | Пройдены форма загрузки, pending, утверждение, поисковый ответ и реальный ИИ-ответ |
| Ссылки руководств и синтаксис Python | Проверены |
| Дополнительный Compose override | `docker compose ... config --quiet` проходит; контейнер этим маршрутом здесь не запускался |
| Регрессионные тесты проекта | 46 обнаружены: 44 прошли, 2 живых ES-теста пропущены в текущем прогоне |

Проверка форматов и версий повторяется без модели:

```bash
.venv/bin/python demo/files/verify_materials.py
```

Эта команда создаёт временные SQLite-базы и не меняет рабочую. Проверки материалов также добавлены в GitHub CI.

Браузер и новый TXT проверялись с локальным Python-backend. Веса и runtime соответствуют модели из `docs/model-provenance.json`; имя API при проверке — `kb-model`, а не Ollama-тег. Ранее основной проект отдельно проверялся с живым Elasticsearch — это отражено в `docs/quality.md`. Новый вспомогательный Docker-маршрут и GPU на компьютере студента требуют собственной репетиции.

Готовые файлы — специально подготовленные примеры, а не независимый тестовый набор. Другие формулировки, длинные/сложные документы и другая модель могут давать иной результат. Неподтверждённые цитаты или числа приводят к отказу публиковать ответ; защита приложения ради показа не ослаблялась. Для процедурного ответа сравнивайте действия, источник и маркер, а не произвольное дословное совпадение черновика модели.
