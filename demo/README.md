# Начни здесь: запуск, файлы и показ проекта

Материалы команды **БВТ2506** для проекта «ИИ-ассистент внутренней базы знаний». Это инструкция для человека, который запускает проект и показывает его преподавателю. Автоматические тесты находятся отдельно, в `tests/`.

## Где лежат документы

**Готовые файлы для чтения и загрузки — в [demo/files](files/README.md).**

| Папка/файл | Что это | Нужно ли загружать вручную |
|---|---|---|
| [`data/documents.json`](../data/documents.json) | Исходный синтетический корпус: 13 записей, 12 действующих разделов | Нет. Загружается автоматически в новую SQLite-базу |
| [`files/01-reference`](files/01-reference) | Читаемые копии действующих исходных инструкций | Нет. Это материалы для знакомства с уже имеющейся базой |
| [`files/02-upload`](files/02-upload) | Новые учебные инструкции в форматах TXT, MD, DOCX, PDF и JSON | Да, через вкладку «Документы», затем утверждение тимлидом |
| [`files/03-updates`](files/03-updates) | Подготовленные версии для показа утверждения и отклонения | Да, в указанном порядке |
| [`files/manifest.json`](files/manifest.json) | Метаданные, вопросы и контрольные маркеры файлов | Нет, это справочник для команды |
| [`data/update-example.json`](../data/update-example.json) | Прежний пример новой версии доступа, также представлен в demo/files | Загружать только для сценария обновления |
| `.local/handbook.sqlite` | Рабочая база, создаваемая при обычном запуске | В GitHub не хранится |
| `.local/demo/<показ>/handbook.sqlite` | Отдельная база конкретной репетиции | Создаётся новым запуском `demo/start_demo.py` |

`data/documents.json` содержит **массив**. Форма загрузки JSON принимает **один объект-инструкцию**. Загружать массив целиком через сайт не нужно.

## Самый короткий путь после установки зависимостей и Ollama

В корне новой версии проекта:

```bash
ollama list
env LLM_PROVIDER=local LLM_BASE_URL=http://127.0.0.1:11434/v1 LLM_MODEL=qwen2.5:1.5b LLM_TIMEOUT=120 ALLOW_EXTERNAL_LLM=false .venv/bin/python scripts/check_model.py
.venv/bin/python demo/start_demo.py
```

Откройте http://127.0.0.1:8501. Новый запуск без `--resume` создаёт отдельную базу с исходными документами. Текущая рабочая база и прежние репетиции не удаляются. В терминале напечатан путь к базе текущего показа.

Этот быстрый вариант использует **локальный Python-поиск**, не Elasticsearch. Для демонстрации обязательного Elasticsearch-контура выполните раздел [«Показ с Elasticsearch»](02-run.md#показ-с-elasticsearch-и-уже-установленной-ollama).

Для первого показа достаточно следовать шагам 1–8 [сценария](04-presentation.md), не загружая весь набор примеров подряд. Режим «ИИ-ответ» требует запущенной модели; «Поиск по инструкциям» работает без её вызова.

Все материалы вымышлены. Модель не обучается при загрузке инструкции, не получает доступ к реальным системам банка и не ищет ответ в интернете. Объяснения ниже соответствуют текущему коду ветки `feature/ai-assistant`.
