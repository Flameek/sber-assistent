# Регистрация инцидента

Учебный материал БВТ2506. Все названия, значения и процедуры вымышлены; это не инструкция Сбера.

> Для чтения. Этот документ уже загружается из исходного корпуса в новую базу. Не загружайте эту копию на основном показе.

- ID: `create`
- Версия: 1
- Система: `реестр`
- Доступ: ib, support
- Приоритет: 30
- Ответственный: Служба сопровождения учебного реестра

## Раздел `new`

Чтобы зарегистрировать новый инцидент, откройте «Реестр → Новая карточка». Запишите время обнаружения, название системы и наблюдаемый симптом. Нажмите «Сохранить» и скопируйте номер карточки.
